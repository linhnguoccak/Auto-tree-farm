# Auto Tree Farmer — Fabric Mod

Tự động trồng, bón bột xương và chặt cây tại khu farm.

## Thông số kỹ thuật
- Minecraft: **1.21.11**
- Fabric Loader: **0.19.3**
- Fabric API: **0.139.5+1.21.11**
- Java: **21**

## Cách build trên GitHub (không cần máy tính)

1. **Fork** hoặc upload repo này lên GitHub
2. Vào tab **Actions** → chọn workflow **Build Auto Tree Farmer**
3. Nhấn **Run workflow** → đợi ~3-5 phút
4. Sau khi xong, nhấn vào build → kéo xuống **Artifacts** → tải `auto-tree-farmer-mod.zip`
5. Giải nén → copy file `.jar` vào thư mục `.minecraft/mods/`

## Sử dụng trong game

| Phím | Tác dụng |
|------|----------|
| **K** | Bật / Tắt Auto Tree Farmer |

Đứng gần khu farm, cần mang theo **Oak Sapling** + **Bone Meal** + đồ ăn trong hotbar.

## Tính năng
- Quét tự động ô farm (bán kính 8 block)
- Trồng Oak Sapling
- Bón Bone Meal đến khi cây mọc
- Chặt cây từ gốc lên ngọn
- Hỗ trợ đa khu (multi-area)
- Tự hồi phục khi máu thấp
